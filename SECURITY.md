# Security policy

## Reporting a vulnerability

Please report security issues **privately** via [GitHub Security Advisories](https://github.com/SirRogersJackBlood/ONYX/security/advisories/new). Do not open a public issue.

Helpful details: the ONYX version (About screen), the device and Android version, steps to reproduce, and the impact you expect.

## Scope

In scope: the Android app, the `core` module (protocol, framing, pairing, message policy) and the website in `site/`.

Out of scope: vulnerabilities in upstream projects (libsignal, Tor, tor-android, IPtProxy, ZXing); please report those upstream. Never include real onion addresses, pairing QR codes or invite links in a report.

## Supported versions

Only the latest pre-release receives fixes.

## Note

ONYX's code was written with AI assistance (Claude, Anthropic) and tested on real devices by its designer, SirRogersJackBlood. Independent review is welcome.
